# Lumen 用户知情同意书

版本：2.0  
生效日期：2026 年 8 月 3 日

欢迎使用 Lumen（以下简称“本服务”）。在您注册 Lumen 账号前，请认真阅读并充分理解本知情同意书。点击勾选并继续，即表示您已阅读、理解并同意本同意书的全部内容。

## 一、账号注册与登录

1. 本服务使用用户名和密码完成账号注册与登录。用户名用于识别您的账号，注册成功后不可自行修改；昵称用于公开展示，可在个人资料中修改。
2. 您应妥善保管用户名、密码及登录设备，不得将账号出借或转让给他人。请勿在其他服务重复使用相同密码。
3. 为保障账号安全、排查异常登录及防止滥用，我们会记录注册与登录时间、处理状态、请求 IP 及必要的安全日志。您的密码不会以明文保存，服务端仅保存使用随机盐和强哈希算法处理后的密码摘要。

## 二、我们处理的信息及目的

为提供本服务，我们可能处理以下信息：

1. 账号信息：用户名、系统生成的用户标识、昵称、头像、城市和个人简介，用于注册登录、展示个人主页及账号管理。
2. 作品信息：您主动上传的照片、标题、说明、拍摄参数、EXIF 信息、拍摄地点和发布设置，用于作品展示、交流、搜索、地图浏览及复刻功能。
3. 互动信息：点赞、评论、关注、收藏、拍摄计划、举报及通知记录，用于实现社区互动和内容治理。
4. 设备与日志信息：IP 地址、访问时间、接口调用结果、故障及安全日志，用于保障服务运行、预防欺诈、处理投诉和履行法定义务。
5. 位置信息仅在您授权系统定位或主动选择地点时处理。您可在发布时调整地点展示范围；精确位置属于敏感个人信息，请谨慎选择公开范围。

## 三、第三方基础设施

为实现必要功能，本服务可能使用以下第三方基础设施：

1. 阿里云对象存储 OSS：存储您主动上传的图片及头像。
2. 阿里云关系型数据库 RDS 及云服务器：存储和处理账号、作品、互动记录及运行日志。

我们会要求相关服务提供方按照适用法律法规及约定采取安全保护措施，不会因接入上述服务而授权其将您的信息用于与本服务无关的目的。

## 四、公开展示与您的责任

1. 您选择公开发布的昵称、头像、作品、文字、拍摄参数及地点信息可能被其他用户查看、分享或用于复刻参考。请勿上传包含他人隐私、未经授权的人像、受限制地点或其他违法侵权内容。
2. 您应确保上传和发布内容具有合法来源及必要授权，并对所发布内容承担相应责任。
3. 我们可能依据法律法规、社区规则或投诉处理需要，对涉嫌违法、侵权或危害安全的内容采取限制展示、删除、暂停账号等措施。

## 五、您的权利

您有权依法查询、更正、补充、复制或删除您的个人信息，撤回非必要授权，注销账号，或对个人信息处理规则提出意见。撤回同意不影响撤回前基于您同意已经进行的处理。部分信息可能因履行法定义务、处理争议或保障安全而在法定期限内继续保存。

如需行使上述权利，请通过应用内反馈渠道联系我们。我们将在核验身份后于法律规定期限内处理。

## 六、信息安全与保存

我们将采取访问控制、传输保护、密码强哈希、最小权限和日志审计等合理措施保护您的信息。我们仅在实现本同意书所述目的所必需的期限内保存信息，法律法规另有要求的除外。互联网服务无法保证绝对安全；如发生可能影响您权益的安全事件，我们将依法处置并通知。

## 七、未成年人

本服务主要面向成年人。未满 14 周岁的未成年人应由监护人阅读并另行完成必要的监护人同意后使用；在相关机制上线前，请勿自行注册。已满 14 周岁但未满 18 周岁的用户应在监护人指导下阅读和使用本服务。
